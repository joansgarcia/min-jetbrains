## 0.1.6 - 2026-11-05

### Fixed

- Compatible with IDE builds newer than 262 (removed `until-build` limit).

## 0.1.5 - 2026-11-04

### Changed

- Decorators and annotations use the keyword color (pink in Min Dark, red in Min Light).
- Parameters and named arguments use the neutral text color (white in Min Dark, dark in Min Light) instead of orange.

## 0.1.4 - 2026-11-03

### Changed

- Single plugin logo (`pluginIcon.svg`) used for both light and dark themes; removed `pluginIcon_dark.svg`.

## 0.1.3 - 2026-11-03

### Fixed

- Plugin logo now shipped as SVG (`pluginIcon.svg` and `pluginIcon_dark.svg`) so it shows in the IDE and Marketplace.

### Added

- Screenshots in the plugin description.

## 0.1.2 - 2026-11-03

### Changed

- Kotlin properties and named arguments use distinct colors.

### Fixed

- Kotlin modifiers (`private`, `const`, `override`, ...) now use the keyword color.

## 0.1.1 - 2026-11-03

### Added

- Islands variants (Min Dark / Min Light).

### Fixed

- Explicit Kotlin highlighting keys.

## 0.1.0 - 2026-11-03

### Added

- Min Dark and Min Light themes (UI + editor color scheme), ported from [Min Theme for VS Code](https://github.com/miguelsolorio/min-theme).
